SPIN! — UX Dissertation Case Study

For my dissertation, I formulated a high-fidelity prototype from ideation to iteration using multiple UX design principles. I followed Jesse James Garrett’s Five Planes of UX to structure the work.

Process (Using the Five Planes of UX)

1 / 3

Strategy

  • Defined concept and naming (using synonyms/associations with “vinyl”).
  • Established brand direction: Skaters font, logo/logomark, black-and-white core scheme.
  • Planned and ran research: consent forms, participant info, privacy notices, interviews, observation, feedback forms.
  • Collected and analysed data: transcriptions, matrices, bar charts to visualise patterns.
1 / 3

Scope

  • Produced participant behavioural observation analysis and user attitude summaries.
  • Created evidence-based design recommendations.
  • Developed personas and user journeys informed by demographic and behavioural data.
1 / 3

Structure

  • Created critical task flows to show how main user groups interact with the service.
  • Developed wireframes and intent frames to define hierarchy and interaction logic.
1 / 3

Skeleton

  • Laid out key pages and supporting screens, ensuring consistent navigation and flow.
1 / 3

Surface

  • Applied visual treatment + interaction detail (hover states, overlays).
  • Used UX principles such as Gestalt proximity, whitespace, and clear grouping.
  • Delivered a complete high-fidelity prototype suitable for iteration and evaluation.
